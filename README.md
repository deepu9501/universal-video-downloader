# Universal Video Downloader

A modern universal video downloader platform supporting:

- YouTube Videos
- YouTube Shorts
- Instagram Reels
- Instagram Videos
- Facebook Videos
- TikTok Videos
- Twitter/X Videos

## Tech Stack

Frontend:
- React.js
- Tailwind CSS

Backend:
- Node.js
- Express.js
- yt-dlp

## Features

- No signup required
- Instant video download
- Mobile responsive
- Fast UI
- Multi-platform support
